# Tierpfoten Darmstadt (fiktiv)

Übungsprojekt aus einer Weiterbildung zum AI Manager: eine ausgedachte Tierheim-Website im Fanzine-Look.
Hunde, Adresse, Telefonnummern und Spendenkonto sind erfunden.

- Statische Seite: `index.html`, `style.css`, `app.js`, Bilder und Schriften in `assets/`
- KI-Funktionen (Frag Wuffi, KI-Rasseberater, Hundeblick) und das Gassi-Wetter laufen über n8n-Workflows.
  Die API-Schlüssel liegen nur in n8n, nicht in diesem Repository.
